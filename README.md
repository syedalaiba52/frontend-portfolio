# 🌐 Personal Portfolio

A modern and responsive personal portfolio website built with **Next.js, React, TypeScript, and Tailwind CSS**.

This portfolio is designed to showcase my skills, learning journey, and future projects as I continue growing as a developer.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern and clean user interface
* Smooth navigation between sections
* Reusable React components
* Developer profile and introduction
* Skills and technologies section
* Project showcase
* Experience section
* Contact section
* Downloadable CV
* Social media links

## 🛠️ Technologies

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **React Icons**
* **Git & GitHub**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/syedalaiba52/portfolio-website.git
```

Navigate to the project:

```bash
cd your-repository
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
